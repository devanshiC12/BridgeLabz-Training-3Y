Box-Sizing Comparison

content-box (default)

Width: 200px + padding 20px + border 5px = total 250px wide.

border-box

Width stays 200px total; padding and border are included inside it.

With box-sizing: content-box (the default), padding and border are added on top of the specified width, making the element larger than expected. With box-sizing: border-box, the padding and border are included within the specified width, keeping the total size predictable.
